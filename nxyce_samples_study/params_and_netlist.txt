================================================================================
 N_xyce_samples study -- setup, circuit, and swept parameters
================================================================================
Study question: how does N_xyce_samples (interface PWL resolution / Xyce print
cadence, dt_print = t_window / N_xyce_samples) affect WR (waveform-relaxation)
convergence cost and coupled-solution accuracy?

--------------------------------------------------------------------------------
 1. CIRCUIT (source: circuit_spec.txt)
--------------------------------------------------------------------------------
   VSIN Bemf s 0 1 2000        ; behavioural back-EMF, 1 V amplitude, 2 kHz sine
   R    Rs   s   cm0  6e-3      ; series resistance 6 mOhm
   L    Ls   cm0 p    1.6e-7    ; series (leakage) inductance 160 nH
   node p = interface port to the field domain

 Driven RL branch (Bemf - Rs - Ls) feeding port p, coupled at p to the field
 domain. t_end = 8 ms = 16 periods of the 2 kHz excitation.

--------------------------------------------------------------------------------
 2. COUPLED NETLIST (WriteCircuitNetlist, matched-secant Thevenin interface)
--------------------------------------------------------------------------------
   BBemf s 0 V = { 1*sin(2*pi*2000*time) }
   RRs   s   cm0 6e-3
   LLs   cm0 p   1.6e-7 IC=0
   * WR interface (voltage-driven): matched-secant Bfield
   VFprev vfprev 0 PWL FILE "vf_prev_k.pwl"     ; field voltage from FEM, prev WR iter
   VIprev iprev  0 PWL FILE "i_prev_k.pwl"      ; field current from FEM, prev WR iter
   Vmeas  p nx 0                                 ; 0 V source -> measures I(Vmeas)
   Bfield nx 0 V = { V(vfprev) + (Rrom + Lrom/(time - t_abs_start))*(I(Vmeas) - V(iprev)) }

   Field response computed by the FEM secant solver using the TRUE (L_FEM,R_FEM).
   (Rrom,Lrom) enter ONLY as the Thevenin preconditioner; at the WR fixpoint the
   (Rrom+Lrom/dt)*(I - i_prev) term vanishes, so the converged solution is
   independent of the ROM values -- the mismatch changes the CONTRACTION rate only.

--------------------------------------------------------------------------------
 3. REFERENCE NETLIST (validation_mode=1, monolithic, real devices)
--------------------------------------------------------------------------------
   BBemf s 0 V = { 1*sin(2*pi*2000*time) }
   RRs   s   cm0 6e-3
   LLs   cm0 p   1.6e-7 IC=0
   Vmeas p nx 0
   Rfem  nx nfem 0.0005        ; real field resistance R_FEM
   Lfem  nfem 0  1.68e-7       ; real field inductance L_FEM (linear; saturation off)
   Single UIC transient over [0, t_end]; step ceiling = t_end/(N_win*N_samp).

--------------------------------------------------------------------------------
 4. FIXED PARAMETERS (held constant across the whole study)
--------------------------------------------------------------------------------
   t_end                    = 8.0e-3 s
   N_field_windows          = 200          (window length = 40 us)
   N_field_eval_intervals   = 1            (one field evaluation per window)
   WRmaxSteps               = 40
   WR_tolerance             = 1.0e-3
   coupling_mode            = 0            (voltage-driven / Dirichlet, default secant)
   reconstruct_mode         = 1            (linear + const average)
   interface_consistency    = 0
   use_t_floor              = 0
   t_floor_frac             = 2.0e-3
   nonlin_model             = 0            (linear inductor; I_sat ignored)

   FIELD (truth, used by both reference and coupled field solver):
     L_FEM = 1.68e-7 H     R_FEM = 5.0e-4 Ohm
   ROM (coupled preconditioner only), +10% mismatch:
     L_ROM = 1.848e-7 H    R_ROM = 5.5e-4 Ohm

--------------------------------------------------------------------------------
 5. SWEPT PARAMETER
--------------------------------------------------------------------------------
   N_xyce_samples in {1, 2, 4, 8, 16, 32, 64, 128, 200}
     -> interface PWL intervals per window (PWL nodes = N+1)
     -> Xyce print cadence dt_print = 40 us / N
   Convergence metric wr_convergence_method in {1 = terminal scalar,
                                                0 = L1 integral on the resample grid}

--------------------------------------------------------------------------------
 6. ACCURACY SUMMARY (coupled vs monolithic reference, common uniform grid)
--------------------------------------------------------------------------------
   Interface current I(Vmeas)   relL2      peak-|I| error
     N=1                        8.6 %      -4.3 %
     N=200                      13.4 %     -7.0 %
   Port voltage V(p): N=1 smooth (peak 0.329 V); N=200 shows per-window spikes
     at the 40 us (25 kHz) window cadence (peak 0.548 V vs reference 0.282 V).

   => N_xyce_samples barely affects physical accuracy; the ~8-13% gap is the
      co-sim WINDOW discretisation (secant field, 40 us windows), NOT the sample
      count. More samples ADD per-window spike noise and cost, and converge slower.
================================================================================
